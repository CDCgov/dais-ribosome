

The output for the `dais-ribosome` consists of two tab-delimited files. One with `.ins` for insertions and `.seq` for sequence related data.

The insertion file header:
Unique_ID<tab>Compound_type<tab>Reference_ID<tab>Protein<tab>Site<tab>Codon<tab>Residue

The sequence file header:
Unique_ID<tab>Compound_type<tab>Reference_ID<tab>Protein<tab>Variant_Hash<tab>Has_Insertion<tab>AA_seq<tab>AA_alignment<tab>cds_id<tab>NT_seq<tab>NT_alignment<tab>Query_nt_alignment_coordinates<tab>Product_nt_alignment_coordinates
